# 00 — 项目管理与制片统筹

**English:** Project Management  
**V0.1 stage:** stage-01 — 项目立项与前期开发  
**Board status:** NOT_YET_RESEARCHED

## 岗位使命

项目管理、预算、资源、进度、风险、组织协作、变更控制与阶段门禁。

## 主要交付物

项目章程、制作计划、预算资源表、风险台账、任务依赖、决策和阶段审查记录。

## 知识库组织

本板块收录经来源固定、许可检查和专业审查的资源。原始来源、研究结论和本项目原创Skill必须分开管理。

当前没有已关联的正式知识条目；不得用相邻岗位资料冒充本节点研究成果。

## 收录与验证要求

- 说明资源实际支持本节点的哪项工作。
- 固定上游仓库、Commit、文件路径和许可证证据。
- 区分静态审查、自动化测试、真实运行和生产验证。
- 记录适用范围、限制、风险、失败模式和下游使用方式。
- 不将模型特定提示词当作通用专业标准。

## 当前缺口与后续研究

尚无足够的专业研究证据。先从真实岗位职责、可靠行业资料和可验证开源实现开展L1筛选，再按价值决定L2/L3。
