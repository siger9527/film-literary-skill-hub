**English:** Creative Development

创意简报、故事概念、世界观、人物关系、故事大纲和可行性评估。

## 收录与验证要求

- 说明资源实际支持本节点的哪项工作。
- 固定上游仓库、Commit、文件路径和许可证证据。
- 区分静态审查、自动化测试、真实运行和生产验证。
- 记录适用范围、限制、风险、失败模式和下游使用方式。
