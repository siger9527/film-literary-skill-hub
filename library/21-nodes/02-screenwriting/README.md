# 02 — 剧本开发与戏剧结构

**English:** Screenwriting  
**V0.1 stage:** stage-01 — 项目立项与前期开发  
**Board status:** KNOWLEDGE_SEEDED

## 岗位使命

将故事设计转化为可读、可演、可拍的结构、场景、动作、对白和修订稿。

## 主要交付物

结构方案、分场表、剧本各稿、场景分析、修订记录和剧本交付包。

## 知识库组织

本板块收录经来源固定、许可检查和专业审查的资源。原始来源、研究结论和本项目原创Skill必须分开管理。

## 收录与验证要求

- 说明资源实际支持本节点的哪项工作。
- 固定上游仓库、Commit、文件路径和许可证证据。
- 区分静态审查、自动化测试、真实运行和生产验证。
- 记录适用范围、限制、风险、失败模式和下游使用方式。
- 不将模型特定提示词当作通用专业标准。
