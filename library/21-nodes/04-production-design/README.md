# 04 — 制作设计与场景美术

**English:** Production Design  
**V0.1 stage:** stage-02 — 导演与视觉前期  
**Board status:** PARTIAL_RESEARCH

## 岗位使命

设计建筑空间、场景、陈设、道具、材料、色彩及时代地域可信度。

## 主要交付物

美术概念、场景设计、空间图、材质色彩方案、陈设道具清单和执行图。

本板块收录经来源固定、许可检查和专业审查的资源。原始来源、研究结论和本项目原创Skill必须分开管理。

## 收录与验证要求

- 说明资源实际支持本节点的哪项工作。
- 固定上游仓库、Commit、文件路径和许可证证据。
- 区分静态审查、自动化测试、真实运行和生产验证。
