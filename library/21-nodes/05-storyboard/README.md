# 05 — 分镜与镜头设计

**English:** Storyboard  
**V0.1 stage:** stage-02 — 导演与视觉前期  
**Board status:** KNOWLEDGE_SEEDED

## 岗位使命

把导演意图转化为镜头序列，明确画面信息、动作阶段、衔接和节奏。

## 主要交付物

分镜、镜头清单、镜头卡、动态分镜/Animatic和连续性标注。
