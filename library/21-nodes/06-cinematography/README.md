# 06 — 摄影指导与镜头语言

**English:** Cinematography  
**V0.1 stage:** stage-02 — 导演与视觉前期  
**Board status:** KNOWLEDGE_SEEDED

## 岗位使命

设计机位、焦段、景别、角度、运动、曝光和画面组织。

## 主要交付物

摄影阐述、镜头规格、机位图、镜头测试、摄影参数和连续性方案。

## 知识库组织

本板块收录经来源固定、许可检查和专业审查的资源。原始来源、研究结论和本项目原创Skill必须分开管理。

## 收录与验证要求

- 说明资源实际支持本节点的哪项工作。
- 固定上游仓库、Commit、文件路径和许可证证据。
- 区分静态审查、自动化测试、真实运行和生产验证。
- 记录适用范围、限制、风险、失败模式和下游使用方式。
- 不将模型特定提示词当作通用专业标准。
