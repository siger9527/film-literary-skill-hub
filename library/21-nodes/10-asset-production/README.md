# 10 — 角色、场景与道具资产制作

**English:** Asset Production  
**V0.1 stage:** stage-03 — 资产与镜头制作  
**Board status:** PARTIAL_RESEARCH

## 岗位使命

按批准设计制作可复用资产，管理身份、变体、状态、版本和依赖。

## 主要交付物

角色场景道具资产、变体表、资产清单、身份锚点和验收记录。

## 知识库组织

本板块收录经来源固定、许可检查和专业审查的资源。原始来源、研究结论和本项目原创Skill必须分开管理。

已关联知识条目：
- [visual-bible-asset-identity-continuity.md](../../../knowledge-base/entries/visual-bible-asset-identity-continuity.md)

## 收录与验证要求

- 说明资源实际支持本节点的哪项工作。
- 固定上游仓库、Commit、文件路径和许可证证据。
- 区分静态审查、自动化测试、真实运行和生产验证。
- 记录适用范围、限制、风险、失败模式和下游使用方式。
- 不将模型特定提示词当作通用专业标准。

## 当前缺口与后续研究

已有部分相关研究或邻接机制，但专业覆盖不完整。后续优先补齐真实工作方法、交付物规范、验收标准和失败诊断。
