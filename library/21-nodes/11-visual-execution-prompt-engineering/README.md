**English:** Visual Execution & Prompt Engineering  
**V0.1 stage:** stage-03 — 资产与镜头制作

将导演与镜头规格编译为模型/工具可执行请求，管理参考、参数和适配。

## 主要交付物

结构化视觉规格、模型适配Prompt、工作流参数、执行配置和诊断。

## 知识库组织

本板块收录经来源固定、许可检查和专业审查的资源。原始来源、研究结论和本项目原创Skill必须分开管理。

当前没有已关联的正式知识条目；不得用相邻岗位资料冒充本节点研究成果。

## 收录与验证要求

- 说明资源实际支持本节点的哪项工作。
- 固定上游仓库、Commit、文件路径和许可证证据。
- 区分静态审查、自动化测试、真实运行和生产验证。
- 记录适用范围、限制、风险、失败模式和下游使用方式。
- 不将模型特定提示词当作通用专业标准。
