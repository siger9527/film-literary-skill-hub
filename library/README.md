# Professional Knowledge Library

The library follows the locked five-stage, 21-node Film Production V0.1 framework. Each node has an independent knowledge board under `library/21-nodes/`. Literary creation, adaptation, AI tools, rights and safety are cross-cutting tags, not additional production nodes.

- [Canonical five-stage / 21-node taxonomy](../docs/FILM_PRODUCTION_21_NODE_TAXONOMY_V0.1.md)
- [Machine-readable 21-node index](../catalog/film-production-21-node-index.json)

A board's existence means only that the category is established. It does not mean professional research, Skill implementation or runtime validation is complete. Each board states its maturity and evidence boundary.
